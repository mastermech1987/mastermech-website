# MasterMech Auto Care Ltd. website
Static SEO-focused website for Cloudflare Pages.

## Deployment
Upload the repository to GitHub, then connect the repo to Cloudflare Pages. No build command is required; the site is static HTML/CSS/JS.

## Before launch
- Confirm the final domain. This project currently uses `mastermechautocare.ca` in canonical URLs, sitemap and structured data.
- Confirm business hours and update LocalBusiness schema if needed.
- Replace placeholder review blurbs with real customer review excerpts only if permission/accuracy is confirmed.
